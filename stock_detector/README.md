# 日本株 検知システム（stock_detector）

Yahoo ファイナンスの日足から、**徐々に上昇している／これから上がりそうな日本株**を
スコアリングして検知するためのモジュール群です。

> ⚠️ 本ツールは投資助言ではなく、候補抽出（スクリーニング）の補助です。
> 検知結果は将来の上昇を保証しません。最終判断はご自身で行ってください。

## クイックスタート

```bash
pip install -r requirements.txt

# 通信不要のデモ（合成データでロジックの挙動を確認）
python -m stock_detector.main demo

# 監視リスト（config.yaml）をスクリーニング ※Yahooへの通信が必要
python -m stock_detector.main screen

# ロジックを過去データで検証
python -m stock_detector.main backtest --horizon 20
```

> 注: Yahoo ファイナンス（query1/query2.finance.yahoo.com）への通信が必要です。
> 制限された環境では `demo` で挙動を確認できます。

## 構成

| モジュール | 役割 |
|-----------|------|
| `data.py` | Yahoo からの価格取得（証券コードは `7203` → `7203.T` に自動変換） |
| `indicators.py` | テクニカル指標（純粋関数。データ取得から独立） |
| `signals.py` | **検知ロジックの中核**（スコアリング） |
| `screener.py` | 複数銘柄の一括評価・ランキング |
| `backtest.py` | ロジックの過去データ検証 |
| `synthetic.py` | 通信不要のデモ/テスト用 合成データ |
| `config.yaml` | 監視銘柄・パラメータ・閾値 |

## 検知ロジックの考え方

5 つの軸を 0〜1 で採点し、重み付き平均で **0〜100 点**の総合スコアにします。
さらに**除外フィルタ**に該当する銘柄は検知から外します。

| 軸 | 重み | 捉えるもの | 主な指標 |
|----|-----|-----------|---------|
| A. トレンド方向 | 0.25 | 今、上昇基調か | パーフェクトオーダー（株価>25>75>200日線）、25日線の傾き、一貫性 |
| **B. 上昇の滑らかさ** ⭐ | **0.30** | *徐々に*＝きれいな右肩上がりか | **log終値の線形回帰の傾き × 決定係数 R²** |
| C. 勢い | 0.20 | 上昇の強さ・転換 | MACD、RSI（50〜70が理想）、ROC |
| D. 出来高の裏付け | 0.10 | 上昇に資金が伴うか | 出来高/平均比、OBV の向き |
| E. これから上がりそう | 0.15 | エントリー妥当性 | 高値ブレイク、25日線からの乖離（押し目〜過熱） |

### 核心：軸 B「上昇の滑らかさ」

「**徐々に**上がっている」を最もよく表すのが、**log(終値) に対する線形回帰**です。

- **傾き（slope）> 0**：上昇している
- **決定係数 R² が高い**：直線によく乗っている＝ノイズの少ない**着実な**上昇

両者の積で採点するため、「傾きは急だが乱高下している急騰株（R² 低）」と
「**緩やかでも一貫して上がる株（R² 高）**」を区別できます。

### 除外フィルタ（誤検知対策）

- **RSI 過熱**（既定 > 78）：買われすぎは見送り
- **25日線からの上方乖離しすぎ**（既定 > 25%）：高値掴み回避
- **流動性不足**（平均売買代金が下限未満）：薄商い銘柄を除外

## パラメータ調整（ロジックを詰める）

`config.yaml` の `weights` / `filters` / `detect_threshold` を変更し、
`backtest` で「検知日の将来リターンが全体平均を上回るか（エッジ）」「スコアと
将来リターンが概ね単調か」を確認しながら調整します。

```bash
python -m stock_detector.main backtest --horizon 20
```

出力例（合成データ）:

```
[20営業日先リターンの集計]
  全 日 平均: 1.51%  勝率 0.629
  検知日 平均: 2.62%  勝率 0.724   ← 検知日のほうが将来リターン・勝率とも高い
  エッジ（検知 - 全体）: 1.11%
```
